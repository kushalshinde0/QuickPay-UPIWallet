# 💸 QuickPay – UPI Wallet

QuickPay is a lightweight UPI-style wallet built with **React**, **Node.js**, **Express**, and **MongoDB**. It allows users to sign up, sign in, check balances, and transfer money securely between accounts.

---

## 🔧 Tech Stack

| Frontend        | Backend          | Database     | Auth         |
|-----------------|------------------|--------------|--------------|
| React (Vite)    | Node.js + Express| MongoDB Atlas| JWT          |
| Tailwind CSS    | RESTful APIs     | Mongoose     |              |

---

## 🚀 Features

- 🔐 Secure user signup & login (with JWT)
- 🧾 View account balance
- 🔎 Search users
- 💸 Send money instantly
- 💬 Clean and responsive UI
